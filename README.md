## Open-source project · omada-inside

**How much data went through my router last month?**
That question led to [omada-inside](https://github.com/wolfgangkiefer1006/omada-inside).
The dashboard uses the TP-Link Omada Open API to show internet traffic
per WAN port and a timeline for troubleshooting Wi-Fi issues.

I’ve shared the source code under the **MIT License** so others can build
on it. If you have an idea, feel free to develop it in your own fork. 
(Special thanks to codex :-))
